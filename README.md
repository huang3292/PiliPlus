## 本地隐藏

入口：`设置 → 隐私相关 → 本地隐藏`；评论区长按、视频三点菜单、动态作者区的「更多」里都有「隐藏此人」，点一下就能把这个人加进规则。

一条规则 = **生效范围**（可多选）+ **若干「且」关系的条件** + **命中后怎么显示**。规则之间是「或」，命中任意一条即隐藏。

### 判定顺序

同一个条目可能被好几个来源盯上，顺序固定，且界面上会说清是哪一条把它藏起来的：

1. 例外名单（手动放行，优先级最高，连 B 站黑名单也能压住）
2. 从条目上点出来的「隐藏此人」
3. B 站黑名单（服务端拉黑的人，只同步 UID，本地不重复写）
4. 手动写的关键词/属性规则
5. 旧的「关键词过滤」表达式

例外只认 UID，不认昵称——昵称随时能改，按昵称放行容易放错人。

### 能用的字段

某个列表接口取不到的字段，在那个范围里就不给选，不会出现「设了但永远不生效」的入口。

| 字段 | 评论 | 视频 | 动态 |
| --- | --- | --- | --- |
| 评论正文 | ✅ | | |
| 视频标题、分区名称 | | ✅ | |
| 动态正文、转发的原文 | | | ✅ |
| 昵称、UID、UID 位数 | ✅ | ✅ | ✅ |
| 用户等级 | ✅ | | |
| 认证状态、大会员类型、有效大会员 | ✅ | | ✅ |

- 文字类：包含、不包含、等于、不等于、开头是、结尾是、正则匹配、正则不匹配（默认忽略大小写，可勾选区分）。
- 数值类：等于、不等于、小于、小于等于、大于、大于等于、介于。
- 等级只有 Lv0~Lv6；UID 是纯数字，位数校验只卡合理上限，不做「多少位以上就是机器人」这种判据。
- 有效大会员看 `vip.status`，过期号即使还留着类型也不算；认证按接口的 `official_verify.type`：`<0` 无认证、`0` 个人认证、`1` 机构认证（空间页的 `official.type` 是另一套编号，不混用）。
- 接口没给某个字段、或者给的是空字符串，一律当「取不到」放行，宁可漏藏也不误藏；反向条件（不包含、不等于）不会因为内容为空就判定成立。

### 命中之后

条目**不会从列表里消失**，而是保留原位置换成占位显示，所以计数、「加载更多」、页码都不受影响，也不会因为一页全被藏住就自动往后翻。

- 视频：占位卡片，保留原封面尺寸和点击区，点一下展开这一条。
- 评论：折叠成一行，点一下只看这一条；主楼被折叠时楼中楼跟着看不到，想单独看可以进这条评论的详情页。置顶评论同样只是折叠，不会被删掉。
- 动态：占位卡片，同视频。
- 也可以整体改成「显示占位卡片」「折叠成一行」或「直接移除」（直接移除才会真的丢掉数据）。默认动作按范围不同：评论折叠成一行，视频和动态显示占位卡片。范围默认在设置页改，单条规则还能单独指定，单条优先。

## 数据存储与迁移

规则存在设置的 `filterRules` 键里（JSON，`version: 2`），因此「导出/导入所有数据」的压缩包会一起带上；规则页右上角还能单独导出或导入 JSON 文件（剪贴板、本地文件、手动输入都行）。导入按规则内容去重，换账号登录可以直接合并。

读不懂的内容不会让功能整体崩掉：坏掉的规则按空规则处理，并在设置页顶部列出丢掉了什么。

旧版本数据的处理：

- v1 的结构化规则会逐条翻译成 v2（正文按范围落到对应字段、认证编号改成接口口径、排除词变成同一条规则里的「不包含」）。已经取消的粉丝数/关注数规则会被丢掉并写明原因，原文先备份到 `filterRulesBackup` 键，出问题可以人工恢复。
- v1 里带「昵称例外」的放行条目不再支持，需要重新按 UID 添加。
- 旧的「关键词过滤」设置页原样保留，写法不变（多个关键词依旧用 `|` 分隔），分区表达式只匹配分区名、不会被当成标题。它不参与上面那套迁移，而是在判定的最后一档实时生效——所以删掉规则页里的规则不会留下看不见的隐藏效果，两套东西不会互相顶掉。

### 目前的边界

- 搜索结果、收藏夹、订阅列表还没有接入隐藏判定；弹幕走 B 站服务端的屏蔽规则，不在这个列表里。
- 改完规则后，已经加载出来的列表不会立刻重算，下拉刷新一次即可。
- 命中隐藏后这一条的手势由占位层接管，想继续操作原条目（例如长按撤销），先点一下展开。要批量调整，还是去 `设置 → 隐私相关 → 本地隐藏`。
- 「关注数/粉丝数」相关的条件已按计划移除，以后再用别的方式实现。
